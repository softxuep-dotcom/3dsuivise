# 《雪地幸存者》可借鉴清单

> 日期：2026-08-13
> 对象：魔兽 RPG《雪地幸存者》（八不戒，2009-05-07；本文以玩家攻略最全的 **1.10** 为准），
> 英文同族是 *Wilderness Survival* / *Wilderness Survival Co-oP*。
> 与 [`复盘-与原图对照.md`](复盘-与原图对照.md) 的分工：那份是**对齐**《荒漠幸存者》，这份是**外借**。

这份不行 —— 我拿到的是百度百科词条、巴哈姆特 1.10 攻略（入门篇 / 进阶篇）、

## 1. 它和《荒漠幸存者》大概率是同一支血脉

不是随便找的一张同类图。四项结构性证据：

| | 雪地幸存者 | 荒漠幸存者 v1.1 |
| --- | --- | --- |
| 温度存在哪 | 木材（攻略原话"右上原木头数位置"） | `PLAYER_STATE_RESOURCE_LUMBER` |
| 体力存在哪 | 英雄魔法值 | 英雄魔法值 0–225 |
| 生命 | 恒定流失，吃烤肉/药草回 | 恒定流失 `regenHP = -0.70/s`，吃熟肉回 |
| 结构 | 白天采集 → 夜里刷怪波 → BOSS | 白天采集 → 夜里狼群 → 狼王 |

把生存轴塞进魔兽的资源槽是常见做法，但**温度→木材、体力→魔法这两条对得一模一样**，
再加上同为"白天采集 / 夜里守"的骨架 —— 合理推测《荒漠幸存者》是这套设计的沙漠版。

**这件事的实际意义**：下面这些不是"从外面引进新玩法"，
更像是**同一套设计在雪原分支上长出来、而沙漠分支上没长的那部分**。移植阻力天然小。

## 2. 值得借鉴的（按 收益/成本 排序）

### ★★★★ 一、夜袭犬去扑火，而不是扑你

**它怎么做的**：狼会去找营火。玩家因此发展出一套完整战术 ——
基地选"只有一个缺口"的地方，入口砌墙，**营火放在离入口最远的角落**，所有人躲到火那边，
狼群全堵在墙外，用远程慢慢点掉。有狼去啃墙？不用管，**啃一会儿它自己就走了**。
要出去就用斧头砍掉一棵树开个口子（明晚再补墙）。

**我们现在**：[`getRaidTarget()`](src/game/simulation/GameSimulation.ts:2459) 直接 `return this.player`。
夜袭犬永远咬玩家，营地、入口、路障只是"玩家碰巧站的那块地"——
路障拦得住狗，纯粹因为狗要过来找你时它挡在路中间。

**移过来是什么样**：夜袭犬优先扑向玩家所在营地的**篝火**，火可以被咬掉燃料甚至咬灭。于是：

- 路障第一次有了保护对象 —— 它护的是火，不是你的碰撞体；
- "今晚回哪座营地"多一层判断：五座营地的火和入口相对位置本来就不一样，
  这层几何差异现在被读出来了（原先五座营地在玩法上是等价的）；
- **主动离开火当诱饵**成为一个战术 —— 不用加任何内容就冒出来的玩法；
- 那条"啃墙的狗会放弃"的规则要一起抄：它让路障不至于沦为无底 HP 洞，
  也让"躲着熬过去"成为正当解法而不是苟且。

**成本**：小。换一个目标点 + 给篝火接上可受击的燃料通道。
**风险**：火灭必须可逆（重新添柴复燃），否则一次失误直接输掉整夜 —— 短局里这个惩罚过重。

### ★★★★ 二、护甲的保暖值 —— 搬到沙漠正好反过来

**它怎么做的**：穿装备提升保暖值，减缓温度流失。雪地里保暖是纯赚。

**我们现在**：[`ARMOR_STATS`](src/game/simulation/GameSimulation.ts:220) 给的是
闪避 / 反伤 / 移速 / 劳力四项，**和体温轴完全不相干** ——
而体温是 README 里自称的"核心轴"。两个系统各跑各的。

**移过来是什么样**：给每件甲一个隔热系数，乘进体温积分。
沙漠里这个系数**天然是双刃的**：镶铁重甲夜里保命、白天让你更快中暑。
于是"白天穿什么、夜里穿什么"成了每天要做两次的决定，
而且它比雪原版本更有意思 —— 雪地里保暖只有好处，沙漠里保暖有账要算。

**这条是全清单性价比最高的一条**：加一个字段、乘一次，
就让两个已经写好的系统第一次发生关系，不新增任何内容。

**成本**：极小。
**顺带**：三阶重甲现在的代价是"移速 −5%"，一个玩家几乎感觉不到的数。
换成"白天更容易中暑"，代价立刻变得看得见。

---

### ★★★ 三、篝火是一台只有一格的机器

**它怎么做的**：营火自带**一个物品槽**。

- 冰丢进去 → 出"水桶"，喝了回 70 水分；
- 易燃物 / 火把丢进去 → 火回满（火把 = 木头丢进火里烧出来的）；
- **丢根骨头进去就把槽占死了**，这时候再丢冰，冰会从旁边弹出来，不变水桶；
- 火还会**自己捡放在旁边地上的柴** —— 出门前把柴堆在火边，你不在家它也能续命；
- 火有两种模式，**"烤肉模式"下不回体温**。一堆火，两个功能，同一时刻只能挑一个。

**我们现在**：篝火只吃枯木换时间（一根 +95 秒），本质是个计时器。

**移过来是什么样**（挑三条，不要全抄）：

1. **一格加工位**。铁矿丢进去 → 铁锭，作为三阶装备的真正门槛（现在是矿石直接合成）。
   烤肉也走同一个槽 —— 于是"这一格现在给谁用"变成一个取舍，而不是两个并行的免费动作。
2. **火边自动取柴**。把枯木放在火边，火自己捡。这直接对上 README 里
   "火只在这 5 座营地烧、营地是地图锚点"的设计意图 —— 出门前囤柴是一个纯正面的准备动作。
3. **烤火 / 烤肉互斥**。一堆火同一时刻只干一件事。我们现在取暖和烤肉共用一个 10 米判定、
   互不干扰，等于白送。改成互斥，"回营地"这段时间里就有了一个要排序的队列。

第 1、3 条是同一个念头的两种强度，**先上第 3 条**（几乎零成本），
觉得不够再上第 1 条。

**成本**：第 3 条极小，第 1 条中小。

---

### ★★★ 四、武器决定护甲精通

**它怎么做的**：斧 / 剑 = 重甲精通，石矛 = 中甲精通（加攻速），石杖 = 轻甲精通（加移速，
配鞋子跑超快）。武器不只是伤害来源，它**指定了你该穿哪套甲**。

**我们现在**：[`装备双线设计.md`](装备双线设计.md) v4 有刀线 / 剑线 × 铁甲 / 皮甲，
四种组合**彼此不发生关系**。玩家最优解是两条线都往上升。

**移过来是什么样**：刀 + 铁甲、剑 + 皮甲各给一个签名加成。
收益不在数值，在**逼玩家开局就选一条路**，短局尤其需要这个 ——
现在一局跑完等于把四样东西都摸了一遍，重开一次没有新东西可看。

**一条重要的注意**：v4 刚刚修完"刀强于剑"（面积是所有输出的乘数，单击只是一个目标的乘数）。
精通加成**不要加在伤害轴上**，否则那份配平要重做。加在非伤害维度：
比如刀+铁甲 → 被围时的减伤，剑+皮甲 → 脱战移速。两条都避开刚配平好的 DPS。

**成本**：小，但要重跑一遍平衡验算。

---

### ★★★ 五、同素材再合成 = 强化；材料分级 = 打猎有了目标

**它怎么做的**：两件事，同一个思路。

- **强化**：鹿皮靴 + 再一张鹿皮 → 鹿皮靴（强化）。靴强化加体力，手套强化变溅射，
  甲强化按比例反伤。不新增图纸，只是"再花一份同样的材料换一个质变"。
- **分级**：虎皮 > 熊皮 > 鹿皮 > 狼皮，**同一张图纸用不同的皮做出来强度不同**
  （虎皮手套 +100% 攻速 / 熊皮 +75%）。所以"今天去打什么"是有答案的，
  而且攻略里明确到"杀鹿捡鹿角别捡鹿皮、杀熊捡熊掌、杀虎捡虎皮"。

**我们现在**：兽皮只有一种，来源是白天的野狗；反伤和闪避我们已经有了
（`ARMOR_STATS.thorns / dodge`）—— 所以**要借的不是效果，是获取结构**。

**移过来是什么样**：把兽皮按来源分级（小狗皮 / 大狗皮 / 头狼皮 / 骆驼皮），
同一个配方用更好的皮做出更强的同名装备。

这一条正好兑现复盘 §3 想要的"让打什么猎变成有意义的选择"，
而且**不新增装备种类** —— 和他们自己定下的"不要照抄 6 阶武器/防具树"不冲突。
复盘里给的方案是把肉分成 10 档，那只影响吃；分级兽皮影响的是穿，杠杆大得多。

**成本**：小到中。

---

### ★★ 六、陷阱：单入口这才守得住

**它怎么做的**：初级工具研究 → 诱捕陷阱（把怪定在门口，**连会遁地的毒蝎被抓住也遁不了**）、
冰霜陷阱（减速 + 伤害）。

**我们现在**：只有被动路障 —— 树桩 800 血 / 6 甲 / 2 自愈，大石 1500 血 / 10 甲。
护甲按减法扣，所以路障天然擅长过滤杂鱼（6 甲对小狗减 41%、对第三夜大狗只减 19%）——
这个设计是对的，但它只能**过滤**，不能**停住**。单人一夜几十只狗，纯血墙只是在拖时间。

**移过来是什么样**：一个消耗品陷阱，摆在入口，定住一只 N 秒。
它把"单一主入口"从**地形几何**变成**玩法**：值不值得为一只大狗花掉一个陷阱，
是个每晚都要做几次的判断。

**成本**：中（新建造物 + 一个定身状态）。走已有的背包建造面板即可。

---

### ★★ 七、白天也该有一次"快回家"

**它怎么做的**：同族地图有环境事件（龙卷风、地震）作为独立于昼夜的压力源。

**我们现在**：白天是纯自由采集，唯一压力是体温慢慢往上爬 —— 而且它的节奏是**可预测**的
（123 秒到中暑线，每天一样）。玩家学会一次，之后每个白天都是同一段流程。

**移过来是什么样**：沙暴。白天随机一次，几十秒预警，期间视野收窄、体温与水分加速流失、
野外持续掉血，营地内免疫。它复用已有的营地几何，让白天也有一次**不可预测的**决策点。

**这条是清单里最"原创"的一条** —— 借的是环境事件在结构里的**位置**，不是具体内容。
要不要做，取决于你觉不觉得白天现在平。

**成本**：中。

---

### ★★ 八、驯养（成本最高，放最后）

**它怎么做的**：杀死大动物后可能出现幼崽 —— 猪 / 麋鹿 / 狼 / 白虎 / 北极熊 / 猛犸 /
雪鹰 / 毒蝎都能养，稀有的能出狼王。喂食时**食物必须放在第一格**，喂食有 CD，
**CD 一转好就得马上喂，否则忠诚度往下掉**。

**我们现在**：有狗巢、夜袭犬、白天野狗 —— 幼崽的来源现成。

**移过来是什么样**：白天打死野狗概率留下幼崽，喂熟肉驯化，夜里帮你挡一口。
**真正的设计价值在那个取舍上：它跟你抢肉。** 我们一个昼夜只需要约 6 块熟肉，
多一张嘴是实打实地疼 —— 这让"养不养"变成一个持续付费的决定，而不是捡到就赚。
单人局里一个同伴对孤独感和难度曲线也都是大补。

**成本**：高（跟随 AI + 忠诚度 + 战斗接入）。

## 3. 不建议借鉴

| 机制 | 为什么不 |
| --- | --- |
| **按格子摆放的合成**（营火 = 打火石(7) + 木头(8) + 易燃物(4)，7/8/4/5/1/2 是背包格号） | 这是那张图最有名的机制，也是 2009 年网吧局的乐趣：背公式、口口相传、专门有人建配方博客。放到 Poki 上是纯劝退 —— 那种乐趣依赖"有个老玩家在旁边带你" |
| **吃东西会被打断**（挨打就停止回血，攻略原话"跟魔兽三国的绷带一样"） | README 已经明确做了相反的决定：开背包暂停游戏，"不存在打斗中来不及"。这是想清楚了的选择，不要回头 |
| **占槽的坑**（丢骨头进营火把槽占死，冰就不变水桶了） | 这类"不知道就会踩"的陷阱，在有老玩家带的多人局里是知识壁垒，在单人浏览器局里只会被读成 bug |
| **属性门槛装备**（铁斧要肌肉 15、弓要敏捷 20、铁杖要智力 15） | 15 分钟的局撑不起一层属性成长。而且我们已经有更好的版本 —— 三阶吃兽皮大头，"打狼喂养打狼的能力" |
| **多人分工与建筑归属**（留一个人守家盖楼做研究、别转让房屋否则科技重置、把工具房藏进树林防拆） | 这套的全部价值来自 10 人协作。单人搬过来只剩点击成本 |
| **三栋建筑的科技树**（工具房 / 武器房 / 防具匠 × 三到四级研究） | 同 "不要照抄 6 阶树"。短局里层数只会摊薄，每层都摸不够 |

## 4. 如果要把这份文档变实

上面标了"中 / 低可信度"的数字，全部来自玩家口述。要变成能进代码的数值，
路径和《荒漠幸存者》那次一样，而且工具都是现成的：

1. 找到 `.w3x`（1.10 生存正式版流传最广，另有 1.16 / 1.27）；
2. `extracted/extracted/_tools\` 的解密脚本改个路径就能跑 —— 当初就是按"可复用到别的保护图"写的；
3. `authoring/tools/wc3/` 的 `units.py` / `items.py` / `abils.py` / `drops.py` / `recipes.py` 原样能用；
4. 重点挖四处：**营火的物品槽逻辑**（一格怎么实现的、模式怎么切）、
   **怪物的目标选择**（是真的寻火还是寻最近建筑）、**护甲保暖值的数值区间**、
   **精通技能的具体加成**。

前两处是这份清单里最值钱的两条，也恰好是最该拿到一手实现来看的两条。

## 5. 一句话总结

**最该抄的两条都不是内容，是关系**：

- 让**狗去扑火** —— 我们已经有五座营地、单一入口、两种路障，
  但它们现在只是玩家站的地方；给它们一个保护对象，这堆几何立刻全部生效。
- 让**甲影响体温** —— 我们已经有三阶甲和一条自称核心的体温轴，
  它们至今没说过一句话。

两条加起来的改动量，比这份清单里任何一条新内容都小。
