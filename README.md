# 雪脊余火（EMBER RIDGE）

面向 Poki 方向的 3D 浏览器生存玩法原型。当前版本专门验证：

- 白天在光秃雪山间收集木头、石块和野果。
- 将可搬运物放到山坳入口形成实体路障。
- 每个山坳拥有固定篝火，木头可直接转化为燃烧时间。
- 狼在夜间从地图边缘逐只进入；多数先巡逻，少数主动袭营。
- 狼具有视野、追击、脱离和可被击杀的生命规则。
- 键盘、鼠标点击移动和触屏双区操作。

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

本原型没有外部美术资源，所有低模场景、角色与特效均由 Three.js 几何体实时生成。
