# 荒漠幸存者（DESERT SURVIVOR）

面向 Poki 方向的 3D 浏览器生存玩法原型，规则以魔兽 RPG《荒漠幸存者 v1.1》为准。

## 五轴生存模型

参考魔兽 RPG《荒漠幸存者 v1.1》改造而来，数值来源与移植取舍见
[`docs/荒漠幸存者-数值分析.md`](docs/荒漠幸存者-数值分析.md)。

| 轴 | 归零后果 | 主要产出口 |
| --- | --- | --- |
| **体力** | 死亡，**每秒恒定流失 0.24** | 熟肉（+14）、休息 |
| **水分** | **立即死亡** | 水（+26）、仙人掌汁（+20） |
| **饥饿** | **立即死亡** | 熟肉（+38）、仙人掌汁（+9） |
| **体温** | 不致死，但**近乎瘫痪** | 篝火升温 / 洗脸水·喝水降温 / Q 就地调节 |
| **劳力** | 采集被拒、攻击伤害 ×0.6 | 站定休息 |

体温是核心：**白天有地板 15、夜晚有天花板 80**，所以中暑只会发生在白天、
失温只会发生在夜晚，而两者的反制手段完全相反 —— 白天喝水降温、夜晚烤火回温。
白天的升温是**日晒基线 +0.69/s**（不区分你在跑还是在站）：从白天地板 15 爬到中暑线
需要 123 秒，正好占一个 180 秒白天的 68% —— 和原图 64% 的比例一致，也就是说
**白天必定中暑，除非你主动降温**。降温三条路：洗脸水（−25~50，最强）、喝水（−14）、
Q 就地取材（−15，零消耗、40 秒冷却）。

水源分两级：**仙人掌**位置随机、一刀出汁，沿途顺手补给；
**干枯的井**是地图预置的 5 口固定水源，提水必出但每口只存 4 格、回蓄一格要 210 秒 ——
一口井只覆盖约 30% 的日常需求，所以井是规划路线的地标，不是水龙头。

生命每秒恒定流失 0.24，把"吃饭"从可拖延的提示变成硬心跳。

夜袭狼**什么都不掉**（沿用原图 Player(11) 不触发掉落表）。夜里打赢只是活下来，
肉和兽皮都必须白天出门拿 —— 打猎和守夜被彻底拆成两件事。
这也修掉了一处供给失衡：一夜刷 40~90 只，按每只 1~2 块肉算就是几十上百块，
而一个昼夜只需要约 6 块熟肉。
累计猎杀 40 只后头狼登场，击杀它即通关。

## 荒漠猎物

移植了原图的 8 种非毒生物（蜘蛛、蝎子、眼镜蛇带 60 秒毒，没有移植）。
它们**都不攻击玩家**，难度只由「警觉半径 + 逃跑速度 + 冲刺时长」三项决定 ——
冲刺耗尽后会停下喘气，所以再快的猎物只要肯追都追得到，代价是你自己的劳力和体温。

| 猎物 | 生命 | 逃速 | 警觉 | 冲刺 | 掉落 |
| --- | ---: | ---: | ---: | ---: | --- |
| 甲壳虫 | 8 | 2.6 | 3.5 | 不限 | 肉×1 |
| 沙虫 | 6 | 7.4 | 5 | 1.4s | 肉×1 |
| 沙鼠 | 12 | 7.6 | 7 | 2.4s | 肉×1 |
| 白颈鼠 | 14 | 7.0 | 6.5 | 2.6s | 肉×1 |
| 蜥蜴 | 16 | 6.2 | 6 | 3.0s | 肉×1 |
| 野兔 | 10 | **9.6** | 9 | 2.0s | 肉×2 |
| 秃鹰 | 10 | 5.2 | 8 | 2.6s | 肉×2 |
| **骆驼** | **90** | **10.5** | 11 | **4.5s** | **肉×4 + 兽皮×2 + 水×2** |

玩家移速 8.2 —— 野兔和骆驼都比你快，正面追不上，只能等它冲刺耗尽。
骆驼是唯一会掉水的猎物（对应原图杀骆驼掉「骆驼水」），一头顶四块肉外加两份水。

## 其它已验证的机制

- 白天在沙丘、砾石滩与盐碱地之间收集枯木、仙人掌汁和铁矿，并搬运入口大石。
- 将可搬运物放到山坳入口形成实体路障。
- 枯木是**背包物品**（对齐原图 I00E），拾取耗 30 劳力、可堆叠 4 根，随身每根 +2 攻击（最多两根）。
  原图靠 150 劳力的采集成本制造稀缺，我们按量程缩到 30 —— 一管劳力三根，而一夜要烧两根。
- 大石**仍是双手搬运**：它是路障，搬运本身就是玩法；木头是材料，搬运只是运输过程。
- 每个山坳拥有固定篝火，在 10 米内按互动键就能从背包取一根枯木添进去，一根 +95 秒。
- 狼在夜间从地图边缘逐只进入；多数先巡逻，少数主动袭营。
- 狼具有视野、追击、脱离和可被击杀的生命规则。
- 真实高度场地形统一驱动外观、角色移动、坡度阻挡、狼群寻路和视线遮挡，不再使用可穿越的装饰山丘。
- 沙丘、砾石、裸岩与洼地盐碱壳按高度和坡度分层，并用荒草、碎石、枯木、废车、石碑和仙人掌建立地图辨识度。
- 营地分为风蚀台地、岩壁洞窟和废弃营地，拥有明显高度差、可行走坡道、磨损路径和单一主入口；入口预留一至两块可搬大石。
- 小狼、大狼与头狼拥有不同生命、攻击、防御、速度和掉落量；每夜怪物 +3 攻 +12 生命且不封顶。
- 白天常驻 5 只游荡野狼，不主动攻击、被打才反击，是兽皮的唯一来源。
- 装备各三阶，一次推进一级：武器 求生匕首 → 粗铁矛（铁3+皮1，攻+18）→ 狼牙重矛（铁5+皮3，攻+16）；
  护甲 粗布衣 → 兽皮衣（皮4，防+4）→ 镶铁重甲（皮6+铁4，防+7、移速−5%）。后两阶都要在燃烧的篝火旁制作。
- 第 3 阶刻意吃兽皮大头 —— 兽皮只从狼身上掉，于是打狼自己喂养打狼的能力。
- 8 格堆叠背包与双手搬运并存，静止 5 秒会在安全条件下自动休息，同时回复生命与劳力。
- 昼夜各 180 秒（首日 90/150 作引导）。与原图 375/375 同为对称结构，所以时间压缩系数
  是全局统一的 ×2.083，所有速率都由原图值乘这个系数得来。
- 每夜狼群以前密后疏的节奏逐只入场，天亮后停止攻击并撤出地图。
- 键盘、鼠标点击移动和触屏双区操作。

在线试玩：[GitHub Pages](https://softxuep-dotcom.github.io/3dsuivise/)

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

运行时地形与道具由共享地图蓝图程序化生成，不依赖外部商业美术资源。可编辑的 Blender 地图源文件位于 `authoring/terrain/ember_ridge_map.blend`，生成脚本和坐标约定见 `authoring/terrain/README.md`。

桌面端使用 WASD / 方向键移动、E 互动（捡柴 / 添柴 / 搬石 / 割仙人掌 / 井边提水）、F 饮仙人掌汁、R 喝水、C 用洗脸水降温、Q 调节体温（偏热降温、偏冷取暖）、空格攻击、B 或 Tab 打开背包。

## 横屏

**本作按横屏布局设计，但不弹方向提示、也不阻断竖屏游玩。**
开始游戏时会静默尝试 `screen.orientation.lock('landscape')` —— 锁上就自动转成横屏，
锁不上（多数浏览器只在全屏下允许）也照样能玩。

HUD 是四角布局（左上目标、右上五条状态轴、左下摇杆、右下双按钮），三档响应式：

- **横屏**：矮屏有两档紧凑布局（≤400px 高、≤340px 高）。实测含中暑徽章的最坏情况下，
  344px 高的横屏状态栏与动作按钮仍有 60px 净空。
- **竖屏**：横向没有余量，居中的时钟和敌人条会压到右上状态栏，所以时钟改为左上纵向排列、
  敌人条挪到底部提示条上方。实测 375×812 无重叠无越界。

`extracted/` 是参考用的魔兽地图解密数据，解析脚本见 [`authoring/tools/wc3/`](authoring/tools/wc3/)，原始导出表见 `docs/data/`。
