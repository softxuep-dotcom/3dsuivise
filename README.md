# 雪脊余火（EMBER RIDGE）

面向 Poki 方向的 3D 浏览器生存玩法原型。当前版本专门验证：

- 白天在裸露荒山与零散积雪之间收集木材、野果和铁矿，并搬运入口大石。
- 将可搬运物放到山坳入口形成实体路障。
- 每个山坳拥有固定篝火，木头可直接转化为燃烧时间。
- 狼在夜间从地图边缘逐只进入；多数先巡逻，少数主动袭营。
- 狼具有视野、追击、脱离和可被击杀的生命规则。
- 真实高度场地形统一驱动外观、角色移动、坡度阻挡、狼群寻路和视线遮挡，不再使用可穿越的装饰山丘。
- 裸土、枯草、岩石与少量积雪按高度和坡度分层，并用荒草、碎石、断木、废车、石碑和稀疏树木建立地图辨识度。
- 山坳分为风口高地、深山洞和废弃营地，拥有明显高度差、可行走坡道、磨损路径和单一主入口；入口预留一至两块可搬大石。
- 小狼与大狼拥有不同生命、攻击、防御、速度和掉落量。
- 狼死亡后掉落生肉与狼皮；4 张皮可制作增加防御的基础皮衣。
- 采集铁矿后，可在燃烧的篝火旁用 3 铁矿和 1 狼皮制作粗铁矛。
- 8 格堆叠背包与双手搬运并存，静止 5 秒会在安全条件下自动休息回血。
- 第一白天 55 秒、第一夜 105 秒；每夜狼群以前密后疏的节奏逐只入场，天亮后停止攻击并撤出地图。
- 键盘、鼠标点击移动和触屏双区操作。

在线试玩：[GitHub Pages](https://softxuep-dotcom.github.io/3dsuivise/)

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

运行时地形与道具由共享地图蓝图程序化生成，不依赖外部商业美术资源。可编辑的 Blender 地图源文件位于 `authoring/terrain/ember_ridge_map.blend`，生成脚本和坐标约定见 `authoring/terrain/README.md`。

桌面端使用 WASD / 方向键移动、E 互动、空格攻击、B 或 Tab 打开背包；移动端界面按横屏布局设计，使用左侧摇杆和右侧行动按钮，不弹出方向提示或阻断游戏。
