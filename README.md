# 雪脊余火（EMBER RIDGE）

面向 Poki 方向的 3D 浏览器生存玩法原型。当前版本专门验证：

- 白天在光秃雪山间收集木头、石块和野果。
- 将可搬运物放到山坳入口形成实体路障。
- 每个山坳拥有固定篝火，木头可直接转化为燃烧时间。
- 狼在夜间从地图边缘逐只进入；多数先巡逻，少数主动袭营。
- 狼具有视野、追击、脱离和可被击杀的生命规则。
- 山体拥有与外观一致的实体碰撞，并会阻挡狼的视野和寻路。
- 狼死亡后掉落生肉与狼皮；生肉可在火边烤熟，4 张皮可制作基础皮衣。
- 8 格堆叠背包与双手搬运并存，静止 5 秒会在安全条件下自动休息回血。
- 第一白天 90 秒、第一夜 105 秒；每夜狼群以前密后疏的节奏逐只入场，天亮后停止攻击并撤出地图。
- 键盘、鼠标点击移动和触屏双区操作。

在线试玩：[GitHub Pages](https://softxuep-dotcom.github.io/3dsuivise/)

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

本原型没有外部美术资源，所有低模场景、角色与特效均由 Three.js 几何体实时生成。

桌面端使用 WASD / 方向键移动、E 互动、空格攻击、B 或 Tab 打开背包；移动端界面按横屏布局设计，使用左侧摇杆和右侧行动按钮，不弹出方向提示或阻断游戏。
